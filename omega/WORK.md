# ChatGPT Chat / Work / Codex access

## ChatGPT Chat
Use the connected GitHub repository `nanamarukanata-hub/hermes-agent` to fetch `omega/AGENTS.md`, `omega/skills/omega-ai-updates/SKILL.md` and `omega/knowledge/latest-releases.md` for tasks that need current OMEGA context. This is opt-in retrieval, not automatic injection into all chats.

## ChatGPT Work
Open a Work task associated with the GitHub repository. Read the OMEGA files, use the shared policy when preparing tests or proposed changes, and open reviewable GitHub PRs if repository write tools are available. Work execution depends on the user's actual mode, permissions and app connections.

## Codex
Checkout the repository and work from `omega/` so its scoped `AGENTS.md` governs OMEGA changes. This does not replace the repository-root Hermes development `AGENTS.md`. Install/use the compatible Skill only if the Codex environment supports it.

## Policy
Cross-product synchronized knowledge is achievable through GitHub files; automatic GPT model training, global chat instructions, and plugin installation are not.
