# Obsidian bridge — Windows and iPhone

The repository directory `omega/knowledge/` contains Obsidian-compatible Markdown. Start from `omega/knowledge/00_HOME.md` and its valid wikilinks.

To use it in Obsidian, clone or export the `omega/knowledge/` directory into a dedicated local vault on Windows. Optionally use a supported Git syncing workflow for this **curated public vault**. On iPhone, configure a trusted compatible sync mechanism separately and test for conflicts before enabling edits on multiple devices.

No direct Obsidian connector was detected in the ChatGPT plugin directory in this setup. GitHub access alone does not create live bidirectional vault synchronization.

Do not mirror private Obsidian notes to the public Hermes repository. Use a separate private vault or private repository and grant any integrations the minimum necessary access.
