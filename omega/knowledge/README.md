# OMEGA Obsidian-compatible Markdown

This folder may be opened or mirrored in Obsidian. It is a curated **public** technical knowledge base only. Never add personal/private notes or credentials to this public GitHub repository.

Suggested YAML metadata: `type`, `source`, `updated`, `verified`, `status`, and `tags`. Verify that internal Obsidian wikilinks point to real notes.

Windows/iPhone Obsidian synchronization has **not** been configured by this repository. Configure a secure local sync or supported Git workflow separately; avoid pushing the personal vault to GitHub.
